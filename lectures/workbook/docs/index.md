# Teachers Workbook

Companion notes for **Best Research and Data Analysis Practices from CERN** — a
course of 13 scheduled lectures and 3 further topics, with a hands-on seminar
in every session from the second on. The lectures
are delivered as Slidev decks; this workbook holds teaching notes and the
hands-on **seminar** briefs.

## This week: 27 October

| | Page |
|--|--|
| Lecture | [06 Version Control with Git](lectures/lecture_6.md): what `git add`, `git commit` and `git push` each do, history and undo, working together in one shared repository or through a fork and a pull request |
| Seminar | [Seminar 6 · Git](seminars/seminar_06.md): clone the weather project, find the commit that changed its mean, take it back, commit your own work and push it to your own GitHub repository |

## Setup

[Setup](setup.md): VS Code, the shell, Git, Python (Miniforge) and a GitHub
account, on macOS and on Windows (Git Bash, or WSL2 if you prefer Linux).

## Hands-on seminars

Every lecture from week 2 on has a paired seminar. All of them work on the
weather project of the lectures, one question per week, in zsh on macOS and
Git Bash on Windows. Students' semester projects are separate and entirely
their own choice. Start here:

- **[Overview](seminars/overview.md)**: the project, the files, and what each
  session asks.

The seminar pages are in the **Seminars** section of the navigation.
