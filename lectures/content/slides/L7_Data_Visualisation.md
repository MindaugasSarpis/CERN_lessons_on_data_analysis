# **Legend**

- ## Legend is a key component of a plot that explains the meaning of the data

- ## Legend might not be necessary if the data is self-explanatory (e.g. bar chart, line chart with one line, plot annotations)

- ## Legend should be placed in a way that it does not obscure the data

- ## Legend should be easy to read and understand

- ## Legend should be consistent with the overall design of the plot

- ## Legend should be used to explain colors, shapes, sizes, and other visual encodings used in the plot

# **Axes**

- ## Axes are the reference lines that define the coordinate system of the plot

- ## Axes should be clearly labeled with units and titles

- ## Axes should have appropriate tick marks and grid lines to help interpret the data

- ## Axes should be scaled appropriately to show the data clearly

- ## Axes should be consistent with the overall design of the plot

- ## Axes should be used to show the relationship between different variables in the data

- ## Axes should be used to compare different groups or categories within the data

# Histograms

- ## Histograms are used to visualize the distribution of a single continuous variable

- ## Histograms should have appropriate bin widths to show the shape of the distribution

- ## Histograms should have clear labels and titles

- ## Histograms should be consistent with the overall design of the plot

- ## Histograms should be used to identify patterns, trends, and outliers in the data
