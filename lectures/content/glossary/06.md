| commit | A recorded version: every staged file, the commit before it, who, when and why. | Where a Change Goes: add, commit, push |

| repository | The project folder together with its `.git` folder, which holds all the commits. | Create the Repository |

| branch | A separate line of commits with a name, such as `main`. | Keep It in the History: commit |
| id | A commit's name: a checksum of all it keeps, the same on every copy. | What a Commit Keeps |

| `git revert` | Adds a commit with the reverse change of another; safe for pushed commits. | Take Back a Commit: revert |
| remote | The same repository on another computer, such as GitHub; usually named `origin`. | A Remote Is a Second Copy |
| `git clone` | Copies a remote to the laptop: every commit and every committed file. | Two Ways to Work Together |
| `git pull` | Fetches the others' new commits from the remote and merges them into your files. | Two Ways to Work Together |
| fork | Your own copy of someone else's repository on GitHub; you may push to it. | Fork: Your Own Copy on GitHub |
