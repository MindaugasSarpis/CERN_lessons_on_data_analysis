| Term | Meaning | First on |
| --- | --- | --- |
| XOR | OR but not AND: 1 when exactly one input is 1. | XOR Is OR but Not AND |
| network | Neurons in layers: the outputs of one layer are the inputs of the next. | A 2-2-1 Network, Weights Set by Hand |
| hidden layer | The layer between inputs and output; it gives the output neuron new coordinates. | A 2-2-1 Network, Weights Set by Hand |
| forward pass | Computing the values from the input, layer by layer, up to the loss. | One Evening Through Two Neurons |
| chain rule | For a function of a function, multiply the slopes of the links: $df/dt = df/da \cdot da/dt$. | The Chain Rule |
| backpropagation | The error at the output, passed back link by link by the chain rule. | Backward, One Link at a Time |
| plateau | A flat stretch of the loss that can stop gradient descent before the lowest point. | Not Every Start Learns XOR |
| language model | Gives every possible next word a probability; the simplest one counts word pairs. | Text as Numbers |
| vocabulary | A model's words or tokens, numbered: tens of thousands in a large model. | Words Become Ids |
| id | A word's number in the vocabulary; it only tells the words apart. | Words Become Ids |
| context | The earlier words a model sees when it predicts the next one. | One Word of Context Is Not Enough |
| vector | A list of numbers; a word's vector says how the word is used. | Words as Vectors |
| dot product | Two vectors' matching entries multiplied and added up: $\mathbf{a} \cdot \mathbf{b} = a_1 b_1 + a_2 b_2 + a_3 b_3 + a_4 b_4$. | Similarity as a Dot Product |
| cosine | The dot product ÷ the lengths: 1 for the same direction, 0 for nothing in common. | Similarity as a Dot Product |
| softmax | Turns scores into probabilities that add up to 1: each $e^{s_k}$ divided by their sum. | Scores into Probabilities |
| temperature | Divides the scores before softmax: low $T$ gives the likely word, high $T$ varied text. | Softmax with a Temperature |
| attention | A weighted average of the earlier words' vectors; softmax turns their scores into the weights. | Context and Attention |
| transformer | The arrangement of today's language models: attention in each of dozens of layers. | Attention in a Large Model |
| LLM | A large language model: next-word prediction by a network, learned from a very large text. | A Large Language Model |
| token | A piece of text: a frequent word, part of a rare word, or a sign. | What a Token Is |
| pretraining | Gradient descent on the mean $-\ln p$ of each next token, over a very large text. | Pretraining |
| instruction tuning | More training on instructions with good answers and on people's choices between two answers. | Instruction Tuning |
| chat | One text, continued token by token: the provider's instructions, the questions, the replies. | Instruction Tuning |
| prompt | The text you write; the reply is the likely text after it. | Prompting, from How It Works |
