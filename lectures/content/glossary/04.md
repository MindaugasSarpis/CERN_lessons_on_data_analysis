| Term | Meaning | First on |
| --- | --- | --- |
| shell | A program that reads a typed line and runs what it names: zsh, bash. | Shell |
| option | A dash and a letter that tell the program how to work: `-n 2`. | The Parts of a Command |
| argument | What the program works on, such as a path; it comes after the options. | The Parts of a Command |
| variable | A name the shell keeps a value under: `name=value` sets it, `$name` reads it. | What the Shell Replaces |
| standard output | What a program prints; `>` writes it into a file, emptying the file first. | Output and Errors Are Two Streams |
| standard error | Errors, on their own stream: to the screen, or into a file with `2>`. | Output and Errors Are Two Streams |
| standard input | What a program reads: the keyboard, a file given with `<`, or a pipe. | Standard Input: `<` and the Pipe |
| pipe | In `A \| B`, the standard output of `A` becomes the standard input of `B`. | Standard Input: `<` and the Pipe |
| filter | A program that reads its input and passes on part of it. | Which Hour Is on Line 5000? |
| mark | A value the logger writes where there was no reading: −999 in `temp_c`. | The Coldest Hour, Filter by Filter |
| `awk` | Runs a small program on every line; prints the lines where a condition is true. | Keep Rows by a Condition: `awk` |
| `grep` | Keeps the lines that contain a text; `-c` counts them, `-v` keeps the others. | Find Rows with a Text: `grep` |
| regular expression | A text with signs in it that describe many texts; regex for short. | Hours Below Freezing |
| single quotes | Every sign between them reaches the program unchanged: the shell replaces nothing. | Put a Pattern in Single Quotes |
| `PATH` | The folders the shell searches for a program, in order; the first found runs. | How the Shell Finds a Program: PATH |
| package | Files with a name and a version, fetched from a repository such as conda-forge. | What a Package Is |
| package manager | A program that installs a package and its dependencies by name: `brew`, `winget`, `conda`. | A Package Manager |
| `conda` | A package manager and an environment manager: installs into one environment at a time. | `conda`: Packages for Python, in Environments |
| environment | A folder with one Python and its packages; one per project. | `conda`: Packages for Python, in Environments |
| `conda activate` | Puts an environment's folder first on `PATH` and its name in the prompt. | One Environment per Project |
| `environment.yml` | The environment written down; `conda env create -f environment.yml` makes it on another laptop. | Write the Environment Down: `environment.yml` |
| checksum | A short number computed from every byte: the same bytes give the same digits. | The Checksum of `weather.csv` |
| 3-2-1 rule | Keep three copies, on two kinds of storage, one of them elsewhere. | Backups: the 3-2-1 Rule |
| exit status | The number a program ends with, 0 for success; `$?` holds the last one. | Exit Status and `set -e` |
| `set -e` | As line 2 of a script, stops it at the first line that fails. | Exit Status and `set -e` |
