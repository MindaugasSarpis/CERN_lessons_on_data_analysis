| Term | Meaning | First on |
| --- | --- | --- |
| algorithm | A finite list of exact instructions that turns an input into an output. | What Is an Algorithm? |
| bit | A binary digit, 0 or 1, held by one switch, off or on. | Bit |
| byte | Eight bits: 2⁸ = 256 possible values, written as two hex digits. | Byte = 8 bits |
| hexadecimal | Base 16, digits 0 to 9 and A to F, four bits per digit. | Hexadecimal |
| two's complement | Negative numbers counted back from zero: in 4 bits, `1111` is −1. | Negative Numbers: Count Back from Zero |
| overflow | A result too large for a fixed-width integer: it wraps around, with no error. | Overflow: 127 + 1 in 8 Bits |
| float | Scientific notation in base 2, in a fixed number of bits; some decimals are rounded. | Floating Point: Scientific Notation |
| float32 | A float in 32 bits: 1 sign, 8 exponent, 23 mantissa; about 7 digits. | float32: Sign, Exponent, Mantissa |
| encoding | The table from characters to bytes; UTF-8 is the usual one. | Text & Encodings |
| ASCII | American Standard Code for Information Interchange: the 7-bit table of 128 characters. | ASCII |
| Unicode | The table that gives every character of every script a number: its code point. | Unicode and UTF-8 |
| UTF-8 | An encoding: each code point in 1 to 4 bytes, ASCII text unchanged. | Unicode and UTF-8 |
| mojibake | Garbled text: the right bytes read by the wrong table, `ą` shown as `Ä…`. | Mojibake: Bytes Read by the Wrong Table |
| LF, CRLF | Line breaks: `0A` (LF) on macOS and Linux, `0D 0A` (CRLF) on Windows. | Encoding and Line Ending in VS Code |
| magic number | The first bytes of a file, saying what it is: `%PDF` for a PDF. | The First Bytes of a File |
| terminal | The window that shows text and passes what is typed to the shell. | Terminal |
| shell | The program in the terminal that runs each typed line: zsh or Git Bash. | Shell |
| working directory | The folder the shell is in; `pwd` prints it, and relative paths start there. | Read the Prompt |
| `ls` | Lists what is in the working directory, or in a named folder: `ls backup`. | Look Around: `pwd`, `ls`, `cd` |
| `cd` | Changes the working directory: `cd data` goes into `data`, `cd ..` one folder up. | Look Around: `pwd`, `ls`, `cd` |
| `mkdir` | Makes a folder; prints nothing when it works. | Change Files: `mkdir`, `cp`, `mv`, `rm` |
| `cp` | Copies a file into a folder, replacing one of the same name without asking. | Change Files: `mkdir`, `cp`, `mv`, `rm` |
| `mv` | Moves a file; a new name in the same folder renames it. | Change Files: `mkdir`, `cp`, `mv`, `rm` |
| `rm` | Deletes a file, or a folder with `-r`, with no Trash and no undo. | Change Files: `mkdir`, `cp`, `mv`, `rm` |
| hash | A checksum that misses no change, such as SHA-256: 64 hex digits. | SHA-256, a Hash |
