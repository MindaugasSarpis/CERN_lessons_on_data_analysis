| Term | Meaning | First on |
| --- | --- | --- |
| interpreter | The program `python`, which carries out the lines one by one from the top. | A First Line: `print` |
| script | Lines of Python kept in a file ending in `.py`. | A First Line: `print` |
| variable | A name with its value; `=` puts the name on the value: `mean = 7.16`. | A Name for a Value: `=` |
| type | What a value is, `int`, `float`, `str` or `bool`; it decides what can be done. | Every Value Has a Type |
| `float` | A number with a point, stored in 64 bits and rounded to about 16 digits. | Every Value Has a Type |
| `str` | Text in quotes: a row of characters with positions counted from 0. | Every Value Has a Type |
| `list` | Values in order, in square brackets; each has a position, counted from 0. | A `list`: Values in Order |
| `float()` | Makes a number from a text; stops with `ValueError` if the text is not one. | Text Is Not a Number: `float()` |
| object | Every value in Python is one; it has a type, a value and methods. | Objects Have Methods |
| method | A function of an object's type, written after a dot: `line.split(",")`. | Objects Have Methods |
| `dict` | A dictionary: pairs `key: value` in curly brackets; a value is found by its key. | A `dict`: Values Found by a Name |
| JSON | A way of writing numbers, texts, lists and dictionaries as text, sent between programs. | An Object from Text: JSON |
| `for` | Runs the block below it once for each item: `for t in temps:`. | `for`: Once for Each Item |
| block | The lines below a line ending in `:`, indented by 4 spaces. | `for`: Once for Each Item |
| `if` | Chooses a block: conditions are tried from the top; the first `True` one runs. | Choose a Block: `if`, `elif`, `else` |
| function | A step written once with `def`, called by its name; `return` hands the result back. | Write a Step Once: `def` |
| parameter | The named input of a function: `line` in `def temp_of(line):`. | Write a Step Once: `def` |
| module | A `.py` file of functions that scripts import, such as `weather.py`. | A Module: a File of Functions, `weather.py` |
| `import` | Finds a module, runs it once and gives it a name. | What `import weather` Does |
| library | Modules someone else wrote and tested, such as `statistics` and `math`, used with `import`. | A Library: Modules Someone Else Wrote |
| standard library | Modules that come with every Python, such as `math`, `json` and `csv`. | Built In, Standard Library, Packages |
| package | A folder of modules, installed together by a package manager: `matplotlib`, `numpy`. | Built In, Standard Library, Packages |
| semantic versioning | Version numbers as major.minor.patch: major may break old code, minor adds functions, patch only fixes. | Reading a Version Number: 2.5.4 |
| environment | A folder with one Python and the packages installed for it; one per project. | An Environment: One Python and Its Packages |
| `environment.yml` | An environment written down: Python and packages with pinned versions, to rebuild it elsewhere. | Write the Versions Down: `environment.yml` |
