| Term | Meaning | First on |
| --- | --- | --- |
| label | The class that happened, $y$: 1 if below 0 °C at 06:00, else 0. | One Evening as Numbers |
| classifier | A rule that turns the inputs into a class, $\hat{y}$; right when $\hat{y} = y$. | One Evening as Numbers |
| accuracy | The share $p$ of $N$ evenings with $\hat{y} = y$, quoted ± $\sqrt{p\,(1 - p)/N}$. | One Evening as Numbers |
| baseline | A rule that ignores the inputs, "never frost"; its 66.3 % is the number to beat. | The Baseline: Never Frost |
| neuron | A weighted sum of the inputs plus a bias, $z$, passed through a step. | One Neuron |
| weight | The number $w_1$ or $w_2$ that multiplies one input in $z = w_1 x_1 + w_2 x_2 + b$. | Weighted Sum, Bias, Step |
| bias | The number $b$ added to $w_1 x_1 + w_2 x_2$; it shifts the line $z = 0$. | Weighted Sum, Bias, Step |
| perceptron | Rosenblatt's neuron of 1958, with the step: $\hat{y} = 1$ if $z > 0$, else 0. | Weighted Sum, Bias, Step |
| decision boundary | The straight line $z = 0$ in the plane of $x_1$ and $x_2$, where $\hat{y}$ changes. | Where the Output Changes |
| XOR | Exclusive or: 1 when the two inputs differ; no single line separates its points. | One Neuron Computes AND and OR |
| Rosenblatt's rule | After each evening, $w \leftarrow w + \eta\,(y - \hat{y})\,x$ and $b \leftarrow b + \eta\,(y - \hat{y})$, $\eta$ the learning rate. | The Rule |
| epoch | One pass of the learning rule over all the evenings. | The Rule |
| linearly separable | Some line has all of class 1 on one side, class 0 on the other. | Linearly Separable |
| convergence theorem | On linearly separable points, Rosenblatt's rule stops after a finite number of updates. | Linearly Separable |
| sigmoid | A smooth step, $\text{sigmoid}(z) = 1/(1 + e^{-z})$: between 0 and 1, 0.5 at $z = 0$. | The Sigmoid |
| logistic neuron | A neuron with the sigmoid, $\hat{y}$ read as $P(\text{frost} \mid x)$; statisticians call it logistic regression. | The Output Is a Probability |
| likelihood | The product $L = \prod_{i=1}^{N} P(y_i)$ of the probabilities the neuron gave to what happened. | From the Likelihood to the Loss |
| cross-entropy | The loss $-\frac{1}{N} \ln L$, the mean of $-\ln P(y_i)$; smallest where $L$ is largest. | From the Likelihood to the Loss |
| training set | The evenings the weights and the bias are learned from: 2016 to 2022. | Train on 2016–2022, Test on 2023–2025 |
| test set | Evenings kept out of training, used once at the end to score the result. | Train on 2016–2022, Test on 2023–2025 |
| cut | The $\hat{y}$ above which "frost" is said; it trades missed frosts against false alarms. | Missed Frosts and False Alarms |
| `predict` | A model's method: an evening's inputs in, 0 or 1 out. | What a Model Holds and Does |
| `fit` | A model's method: evenings and labels in, its numbers change. | What a Model Holds and Does |
| `class` | The type of an object; `Perceptron()` makes one and runs its `__init__` once. | What a Model Holds and Does |
| `self` | Inside a method, the object itself; `self.w` keeps a value in it. | The Same Code as a Class: `Perceptron` |
