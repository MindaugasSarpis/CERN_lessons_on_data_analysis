| Term | Meaning | First on |
| --- | --- | --- |
| model | A formula with numbers left open, its parameters; the data set them. | A Model Has Parameters |
| parameter | A number a model leaves open: μ, or a and b of a line. | A Model Has Parameters |
| fitting | Finding the parameter values with the smallest miss between the model and the data. | Three Models of the Weather Log |
| derivative | The slope of a curve at one point: $(S(\mu + h) - S(\mu))/h$ for a very small h. | The Derivative: How Fast S Changes |
| least squares | Choosing the values with the smallest sum of squared misses; for a constant, the mean. | The Mean Is the Least-Squares Value |
| probability density | Probability per unit of the value: 0.47 per °C, so about 0.047 in 0.1 °C. | How Probable Is 2016? |
| likelihood | The densities of the values multiplied, as a function of the parameters: $L(\mu) = \prod_i p(y_i \mid \mu)$. | The Likelihood of Ten Years |
| maximum likelihood | Choosing the parameter values that make the likelihood L largest. | The Likelihood of Ten Years |
| χ² | Chi-squared: $\sum_i (y_i - f(x_i))^2/\sigma^2$; for Gaussian scatter, minimum χ² is maximum likelihood. | Maximum Likelihood Is Minimum χ² |
| pull | A miss in units of σ, $(y_i - f(x_i))/\sigma$; χ² is the sum of their squares. | χ² of the Flat Line, Year by Year |
| closed form | A formula for the best parameters, from the derivatives set to zero and solved. | The Best Line in Closed Form |
| partial derivative | The derivative when one parameter moves and the others stay: $\partial\chi^2/\partial a$. | The Derivatives of χ² for a Line |
| normal equations | Both derivatives of χ² set to zero: two equations for a and b. | The Normal Equations |
| intercept | The value of the line at x = 0: b̂ = 7.41 °C, the line in 2016. | Why x Counts from 2016 |
| Δχ² = 1 | Moving a fitted parameter by one σ raises χ² by 1 above its minimum. | χ² Around Its Minimum |
| gradient descent | Following the derivative downhill a step at a time: $\theta \leftarrow \theta - \eta\,dS/d\theta$. | The Update Rule |
| step size | The learning rate η, chosen by hand: too large overshoots, too small creeps. | The Update Rule |
| starting values | The parameter values a descent starts from, read off a plot of the data. | Two Days Pushed Through |
| residual | What the fitted model leaves: $r_i = y_i - \hat y_i$; a good model leaves only scatter. | Residuals: What the Model Leaves |
| degrees of freedom | The points minus the fitted parameters, ndf = N − k: a right model's expected χ². | What χ² Should Be |
| overfitting | Fitting the noise: too many parameters, a curve through every point, a wild forecast. | A Curve Through Every Point |
| statistical uncertainty | The ± from the scatter of the points: the one a fit gives. | A Shift the Fit Cannot See |
| systematic error | An error shared by many points, such as a sensor shift; χ² cannot see it. | A Shift the Fit Cannot See |
| Levenberg–Marquardt | The minimiser in fitting programs: short downhill steps far away, Newton steps near the bottom. | Newton's Step and Levenberg–Marquardt |
| p-value | The chance of a χ² this large or larger, if model and σ are right. | The χ² Distribution and the p-value |
